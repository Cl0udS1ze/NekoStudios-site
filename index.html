About the studio

Built from ideas. Driven by imagination.

NekoStudios is an independent studio creating games, software and experimental AI systems.

We build interactive worlds, develop useful digital tools and explore new ideas through technology.

Our software projects include experimental utilities and the AI system NEIRON, which is being built from the ground up and is still in development.
